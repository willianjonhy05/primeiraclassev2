## 📌 Sobre o Projeto

Este projeto consiste em uma **landing page institucional e comercial** projetada para a **Primeira Classe**, empresa focada em engenharia de software e desenvolvimento de sistemas online personalizados.

A interface foi concebida com estética escura (*dark theme* corporativo), toques em degradê com efeito glassmorphism e tipografia moderna, priorizando a velocidade de carregamento, navegação limpa e adaptação consistente em dispositivos móveis, tablets e monitores widescreen.

---

## ✨ Funcionalidades

- **Design Responsivo & Mobile-First:** Experiência consistente e fluida em smartphones, tablets e desktops.
- **Navegação Suave (*Smooth Scroll*):** Rolagem natural ao clicar nos links do menu.
- **Menu Hamburguer Interativo:** Transição otimizada para navegação em telas compactas.
- **Seção Hero com Prova Social:** Métricas em destaque e chamadas de ação claras (CTAs).
- **Apresentação de Serviços e Diferenciais:** Grid semântico com cartões informativos sobre desenvolvimento sob medida, APIs e arquitetura em nuvem.
- **Formulário de Captação / Orçamento:** Validação simples e simulação de envio de dados com feedback visual imediato para o usuário.
- **Boas Práticas de SEO & Acessibilidade:** Uso correto de tags semânticas (`<nav>`, `<header>`, `<section>`, `<footer>`) e contraste calibrado.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído propositalmente com tecnologias puras (Vanilla), sem dependência de frameworks ou bibliotecas externas pesadas:

- **HTML5:** Estrutura semântica e acessível.
- **CSS3:** Custom properties (variáveis CSS), Flexbox, CSS Grid, Glassmorphism e Media Queries.
- **Vanilla JavaScript:** Interações com DOM (menu retrátil e submissão de formulário).
- **Google Fonts:** Tipografia utilizando a família [*Plus Jakarta Sans*](https://fonts.google.com/specimen/Plus+Jakarta+Sans).

## 🚀 Como Executar o Projeto

Como o projeto utiliza apenas recursos nativos da web, não é necessário instalar dependências ou configurar ambientes Node.js:

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/willianjonhy05/primeiraclassedev2.git
   ```

2. **Acesse o diretório:**
   ```bash
   cd primeira-classe-landing-page
   ```

3. **Abra o arquivo:**
   - Dê um duplo clique no arquivo `index.html`, ou;
   - Abra utilizando a extensão **Live Server** no Visual Studio Code.
